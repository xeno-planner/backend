# XENO Planner | Backend

## Running in Compose

First of all, clone project.
```shell
git clone https://github.com/xeno-planner/backend.git <DIR_NAME>
cd <DIR_NAME>
git fetch
git checkout legacy
```

Then, we can run it with ``docker compose``
```shell
docker compose up
```
